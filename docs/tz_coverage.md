# Покрытие ТЗ: «Система для организации киберспортивных турниров»

Документ фиксирует, где в проекте реализованы функции из ТЗ. Это удобно использовать на защите как чек-лист.

## Реализованные функции

| Требование | Где реализовано | Как показать |
|---|---|---|
| Регистрация команд и игроков с подтверждением рейтинга | `TeamsController`, страница `/teams/` | Капитан создаёт команду, добавляет игроков и рейтинг; админ/судья подтверждает рейтинг. Без подтверждённого рейтинга заявку нельзя принять. |
| Планирование сетки турнира | `TournamentPlanningService`, `/tournaments/<id>/?tab=overview` | Админ выбирает single/group, нажимает «Сгенерировать сетку». Посев идёт по среднему рейтингу игроков. |
| Одиночная сетка | `BuildSingleEliminationTree` | Создать турнир single, подтвердить команды, сгенерировать сетку. |
| Групповой этап | `BuildGroupStageMatches`, `BuildStandings` | Создать турнир group_stage/groups, сгенерировать группы и показать таблицу групп. |
| Трансляция результатов в реальном времени | `MatchesController`, `MatchesHub`, `/hubs/matches` | Открыть матч-центр в двух вкладках, изменить счёт — обновление приходит через SignalR. |
| Discord-интеграция | `DiscordWebhookService` | Создать турнир или перевести матч в Live — сообщение уходит в Discord. |
| MVP-голосование | `MvpController`, вкладка MVP | Админ открывает голосование, пользователь голосует за игрока, результаты пересчитываются. |
| Призовой фонд и выплаты | `TournamentManagementController`, вкладка «Призовые» | Настроить проценты, нажать «Распределить выплаты», затем «Подтвердить выплаты». |
| Twitch/YouTube стримы | `MatchesController.SetMatchStream`, `StreamsController` | На вкладке «Стримы» привязать ссылку Twitch/YouTube к матчу. |
| Аналитика | `AnalyticsController`, `/analytics/` | Показать статистику игроков, дисциплины, live-матчи, стримы, CSV-экспорт. |
| Админ-управление этапами | `TournamentManagementController.SetStage` | На вкладке «Обзор» сменить статус planned/live/paused/finished. |
| Распределение команд по рейтингу | `TournamentPlanningService.SeedTeams` | Добавить рейтинг игрокам, подтвердить и сгенерировать сетку — сильные команды получают seed выше. |

## Учебные допущения

- Steam/Faceit/PandaScore работают как optional-интеграции: если ключи не заданы, основной локальный сценарий не ломается.
- Выплаты не отправляют реальные деньги: система формирует прозрачную таблицу payout-ов и статусы `pending/paid`.
- Twitch/YouTube интеграция реализована через ссылку на стрим, без обязательной авторизации в их API — этого достаточно для демонстрации внешней интеграции.
- Правило завершения матча учебное: если одна из команд набрала 16+ очков, матч считается завершённым.
